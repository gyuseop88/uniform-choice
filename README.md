# 교복 디자인 입혀보기 (대룡중 학생자치회용)

## 1. 폴더 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 프로그램 본체 |
| `items.js` | 카탈로그에서 뽑아낸 디자인 목록 (739개) |
| `pack/` | 옷 이미지 묶음 12개 (t_=목록용 작은 그림, i_=입혀보기용) |
| `firestore.rules` | Firestore 보안 규칙 (콘솔에 붙여 넣기) |

## 2. 입장코드 (기본값)

- 학생: `dr2026`
- 선생님: `drteacher` → 선생님 코드로 들어오면 **⚙ 관리** 버튼이 보여요.
- 코드를 바꾸려면: 관리 → 설정 → **입장코드 바꾸기**에서 해시값을 만든 뒤, `index.html`의 `STUDENT_HASH` / `ADMIN_HASH`에 붙여 넣으세요.

## 3. 바로 써 보기 (설정 없이)

`index.html`을 더블클릭하면 **로컬 모드**로 실행돼요. 투표는 그 컴퓨터에만 저장됩니다.

## 4. 학생들과 함께 쓰기: Firebase 연결

1. Firebase 콘솔에서 프로젝트를 만들고 **Firestore Database**를 생성해요.
2. 규칙 탭에 `firestore.rules` 내용을 붙여 넣고 게시해요.
3. 프로젝트 설정 → 내 앱 → 웹앱을 추가한 뒤, 표시되는 `firebaseConfig` 값을 `index.html` 위쪽 `CONFIG.FIREBASE`에 붙여 넣어요.
4. 저장한 컬렉션 이름은 `uniform2026_votes`, `uniform2026_settings`, `uniform2026_items`예요.

## 5. GitHub Pages 배포

1. 새 저장소에 이 폴더 안의 파일을 **전부** 드래그해 올려요 (pack 폴더 포함, 총 16개).
2. Settings → Pages → Branch: `main` / `(root)`로 설정하면 1~2분 뒤 주소가 생겨요.
3. 학생들에게는 주소와 학생 입장코드만 알려 주세요.

> ⚠️ **공개 범위 주의**
> 무료 GitHub Pages는 저장소가 **공개(Public)** 여야 해요. 그러면 업체 카탈로그 사진 파일도 주소만 알면 누구나 볼 수 있어요.
> 입장코드는 화면을 가리는 가벼운 잠금일 뿐이에요. 선정 기간이 끝나면 저장소를 **삭제하거나 비공개로 전환**하는 걸 권장합니다.

## 6. 기능 요약

- **왼쪽:** 회사 탭 + 품목 필터 (후드집업·후드티·맨투맨·야구잠바·반팔/긴팔 체육복·하복 생활복 상의/하의·동복 생활복 하의)
- **오른쪽:** 남학생·여학생이 동시에 입어 봐요. 겉옷 / 상의 / 하의 3겹이고, 회사를 섞어 조합할 수 있어요.
- **♡ 찜**, **🗳 조합 투표**: 기기당 마지막 제출 1건만 집계돼요.
- **관리 화면:**
  - 품목별 순위, 인기 조합 TOP 10, 학생 한마디, CSV 내려받기
  - 블라인드 모드 (회사명을 A사·B사·C사로 표시), 투표 열기/닫기
  - **PDF로 디자인 추가**: 새 카탈로그 PDF를 브라우저에서 읽어요. 옷 부분을 드래그하면 배경을 지우고 목록에 추가합니다 (Firebase 연결 시 모든 학생에게 보여요).

## 7. 알아 둘 한계

- 입혀보기는 사진을 오려 붙인 **콜라주 방식**이라 실제 핏과는 달라요. 모델마다 포즈가 달라서 소매나 머리카락이 조금 삐져나올 수 있어요.
- 카탈로그에 원래 있던 워터마크(SMART, ELITE 글자)가 옷 위에 흐리게 남아 있는 경우가 있어요.
- 블라인드 A/B/C 표기는 고정이에요 (A=스마트, B=엘리트, C=스쿨룩스).
- 관리자 여부는 브라우저에 저장돼요. 보안이 필요한 자료는 넣지 마세요.
